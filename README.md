# KakaoTalk PC App Skills

Practical Codex skill notes for operating the KakaoTalk PC app on macOS through Computer Use.

This repository starts small and is meant to grow from observed UI patterns. The skill focuses on:

- Opening KakaoTalk PC chats
- Navigating visible chat list and chat windows
- Sending messages only after required confirmation
- Learning safe procedures for attachments, calls, emoticons, scheduled messages, and other KakaoTalk PC actions

The skill avoids storing private chat content, real contacts, phone numbers, payment details, or personal screenshots.

## Skill

- `kakaotalk-pc/`: Codex skill folder

## Safety

KakaoTalk actions often communicate with third parties or handle sensitive data. The skill requires confirmation before sending messages, making calls, uploading files, scheduling messages, sharing links, sending money, or otherwise transmitting data.
